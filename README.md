# JJ Movies downloads

Official JJ Movies Android and Windows app downloads.

Download installers from the [Releases page](https://github.com/jacajericho2026-sketch/JJMovies-Releases/releases). Check each release description for its version, platform, signing status and installation instructions. Compare downloaded files against the included SHA256SUMS.txt.

Windows Setup supports installation and compatible in-place updates. Portable builds run without installation. Android updates require a matching package and signing identity and system installation approval.

This repository contains release files and release notes. Source code is maintained separately. A public download does not grant an open-source license. Third-party components remain subject to their respective licenses.

Never upload private signing keys, signing backups, passwords or access tokens here.
